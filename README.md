# RefinedReal 🛍️

A modern, clean, and responsive e-commerce website built with Next.js, React, and Tailwind CSS.

## ✨ Features

- 🏠 Modern and responsive homepage
- 🛍️ Product listing
- 🔎 Product search
- 🏷️ Category filtering
- 💰 Price filtering and sorting
- 📦 Product details page
- 🛒 Shopping cart
- 💳 Checkout page
- 🌙 Dark / Light mode
- 📱 Mobile responsive design
- ⚡ Fast and modern UI
- 🎨 Clean and user-friendly design

## 🧰 Technologies Used

- Next.js 14
- React 18
- JavaScript
- Tailwind CSS
- Lucide React
